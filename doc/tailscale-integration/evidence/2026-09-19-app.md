## 新增覆盖

- `timed_notification_coordinator_test.dart` 增加在定时更新尚未完成时收到断线取消的测试，验证操作严格串行：先完成 `sound=false` 的排程，再执行一次取消。既有测试同时覆盖 `sound=true`、`sound=false`、重复状态去重、更新、取消后重建。

## Android 模拟器中止

为运行上述集成测试，曾启动唯一的 `MonkeyCraft_Roadmap_Test`（arm64、API 36）实例。首次尝试约 60 秒内没有注册到 adb，未运行 APK 构建或 integration test；`adb devices` 为空，无法读取 boot 状态或 logcat。此时收到 Android 崩溃报告，立即停止该实例，未启动第二个实例。

停止前 qemu 进程 RSS 为 172224 KB；可读取信息中没有 `Fatal`、`crash`、`OutOfMemory`、`low memory` 或 `killed` 记录，且没有可用 emulator/qemu 启动日志。因此不能将用户报告归因于本次启动，也没有 OOM 证据。首次尝试的 Android 原生集成**未执行**；第三次启动的结果见下文。

按后续核对，主机没有 swap I/O，且旧崩溃报告均来自 9 月 18 日的主动退出路径 `skin_winsys_quit_request` → `abort`，不是本轮 App 崩溃或 OOM。

第二次尝试严格使用单一 detached `Popen(start_new_session=True)` 进程，标准输入为 `/dev/null`、输出写入 `/tmp/monkeycraft-roadmap-avd-20260919.log`，参数为 `-no-snapshot -gpu software -no-audio -no-boot-anim`。`emulator -help-gpu` 确认 `software` 为支持值。等待超过三分钟后，qemu 仍处于运行状态（约 99% 单核 CPU、RSS 约 312 MB），没有 ADB transport。日志在旧崩溃报告的上报同意提示处停止；后续确认其后的 module annotations 是旧 dump，不是该次启动参数或内存状态。由于没有可用 serial，无法使用 `adb emu kill`，在超时后直接 `KILL` 该唯一实例，并保留 AVD 数据。主代理请求采样时进程已退出，因此没有有效的进程栈样本。随后清理了本次手工建立的离线 ADB 连接并重启 adb server；最终 `adb devices` 为空。

该 detached 启动日志 SHA-256 为 `264410010581266d0f6d2c17fdce07436d5d68ec7efa6ff8e84c0baa1bbbb95c`，本机受控路径为 `/tmp/monkeycraft-roadmap-avd-20260919.log`。它不包含 App、账户、登录地址或 peer 数据。

第三次启动在相同 detached 方式下增加 `-crash-report-mode disabled -no-metrics`，绕过旧 crash dump 的上报同意流程，保留 crash database 和全部 AVD 数据。API 36 arm64-v8a 在约 19 秒完成引导；随后执行 `flutter test integration_test/android_tailscale_native_test.dart -d emulator-5554`，两项通过：原生通知通道传递 `sound=false` 与 `sound=true` 并执行倒计时 start/update/cancel，及内嵌节点 diagnostics、start/stop/restart/cancel 与状态事件。测试没有调用交互登录、账户授权或 peer dial。运行后仅统计 `netlinkrib`、netlink `EACCES`、Tailscale fatal/error 和 `Fatal Exception` 的相关 logcat 行，结果为 0。它不是 Android 真机或 tailnet 登录/连通性证据。实例使用 `adb -s emulator-5554 emu kill` 正常关闭，确认无 ADB 设备、无 qemu 残留。第三次启动日志 SHA-256 为 `7561550e9ce0618352a077b5d9703ee1c9576c2df857ee0d6f7eaca67b2f5258`，位于 `/tmp/monkeycraft-roadmap-avd-20260919-attempt3.log`；未将其内容或敏感运行数据纳入仓库。

## 证据边界

模拟器、离线 MethodChannel 往返和 Dart 测试均不能证明 Android 真机的 SELinux/netlink 行为、Tailscale 登录/恢复、后台音频恢复、系统通知实际出声或 tailnet peer 连通。后续恢复 Android 验证前，应先取得并确认崩溃设备与时间点的实际日志。

## EventChannel stopped 回归复验

在最终 APK 已由主代理另存后，重新启动唯一 `MonkeyCraft_Roadmap_Test` API 36 模拟器，使用 `-crash-report-mode disabled -no-metrics -no-snapshot -gpu software -no-audio` 运行更新后的 `flutter test integration_test/android_tailscale_native_test.dart -d emulator-5554`。两项测试均通过。

内嵌节点场景现在在 stop 后确定性等待 EventChannel 的 `stopped` 快照（5 秒 timeout），若收到 stop 后 `failed` 则立即失败，并在第二次 stop 后断言本段事件没有 failed；该断言在本次实际运行中通过。未执行登录、账户授权或 peer dial。运行结束以 `adb -s emulator-5554 emu kill` 正常关闭模拟器，确认 adb 无设备。

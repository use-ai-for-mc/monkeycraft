# 2026-09-19 Firefox WebCodecs 回归

## 范围

本次在 Playwright 官方托管的 Firefox 155.0 中验证桌面网页端。浏览器由 `node node_modules/@playwright/test/cli.js install firefox` 下载到 Playwright 缓存，以临时资料目录启动；没有启动、修改或读取系统 Firefox 及其个人资料。

网页使用现有 `web/dist` 的 Vite 静态预览 `http://127.0.0.1:4187`，浏览器从 `http://localhost:4187/?debug=1` 访问。视频来源是本地回放夹具 `ws://127.0.0.1:9602`，参数为 `streaming-360x640` 和测试密码 `test`。未连接 Minecraft、真实 9600 服务、用户账号或用户控制器。

## 结果

Firefox 155.0 的页面上下文为安全上下文；`VideoDecoder` 和 `EncodedVideoChunk` 都存在，`VideoDecoder.isConfigSupported({ codec: "avc1.420028", optimizeForLatency: true })` 返回支持。

登录本地回放后，流页面实际收到并解码夹具：调试统计为 `recv 6`、`dec 5`、`err 0`、`cfg 1`，协商视频尺寸为 `360x640`，链接状态为 `connected`。未出现网页的 WebCodecs 不支持遮罩。随后可从流工具栏打开聊天面板，聊天输入框存在，说明该已连接会话的聊天路径仍可用。

## 命令与日志

运行命令：

```text
node node_modules/@playwright/test/cli.js install firefox
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 4187 --strictPort
node tools/replay-server.ts --port 9602 --fixture streaming-360x640 --password test
node /tmp/monkeycraft-firefox-probe.mjs
```

完整的安装、预览、回放和探测输出位于 `outputs/roadmap-2026-09-19-firefox/`。探测结果不代表所有 Firefox 版本、真实游戏网络、硬件解码路径或完整游戏 UI 验收；它仅覆盖此台主机上 Firefox 155.0 对当前网页产物的本地 H.264 WebCodecs 解码和聊天入口。

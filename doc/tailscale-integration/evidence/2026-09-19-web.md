## P4 只读事实

`web-tailscale/` 是未跟踪的隔离实验，固定 `tailscale.com v1.102.3` 和指定 commit；`LOCK.json` 记录 WASM 与同工具链 `wasm_exec.js` 的哈希。它没有接入 `web/`、Flutter、Mod 或发布链。

可复用的非产品资产包括：Worker RPC v1 schema、受限 `dialTcp` 的参数校验、单连接限制、RFC 6455 帧实现、假后端测试、上游固定与 WASM 重建脚本。当前产物约 43 MB，且真实 tailnet/DERP 视频、Safari、iOS 和任意 Minecraft 端到端均未验证。

有一项必须在复用前澄清的文档/实现差异：`web-tailscale/js/worker.js` 的 `notifyBrowseToURL` 事件 payload 含原始 `url`，而 `docs/WORKER_RPC.md` 声称该事件仅发送 `hasUrl` / `fallback`。这会把登录链接从Worker传给同源页面，不符合该POC自己的最小暴露说明；页面是否需要此URL打开登录、是否被持久化或泄漏，还要结合最终交互和信任边界判断，不能仅凭此项宣称漏洞。本文不修改未跟踪实验，也不把它视为可发布实现。

P4 备选架构、决策依赖和推荐见 [P4 Web 托管准备](../P4_WEB_HOSTING_PREPARATION.md)。

## Android Chrome 本地回放（模拟器）

本节是在 `MonkeyCraft_Roadmap_Test` Android 16 / API 36 模拟器中运行的 Chrome 133.0.6943.137。它是 Android Chrome 实例，但不是物理手机。模拟器以 `-no-audio` 启动，测试只连接本机回放夹具，不连接 Minecraft、tailnet 或账户。

启动本机 Vite preview 与既有 `streaming-360x640` 回放服务器后，使用 `adb reverse` 将设备的 `127.0.0.1:4173`、`127.0.0.1:9601` 映射到本机。Chrome 用回放密码连接，回放服务器收到 Android Chrome 的认证、`CLIENT_STATUS` 与连续 ACK；没有输出或保存认证材料。

Chrome 的页面调试层在竖屏显示 `recv 98`、`dec 97`、`err 0`、`cfg 1`、`avc1.420028`、`link connected`，证明本次录制流由 Android Chrome 的 WebCodecs 路径实际解码。回放持续时旋转到横屏，客户端上报尺寸从 `504x960` 改为 `960x338`；恢复竖屏后重新上报 `504x960`，连接与单次 decoder configure 保持正常。

用 Android 的真实触摸注入在摇杆上开始并向上拖动，回放服务器收到 `INPUT W pressed=true`。随后打开系统设置使 Chrome 失焦，服务器收到对应的 `INPUT W pressed=false`，证明该设备路径会释放被按住的触控输入。此项只覆盖摇杆与失焦释放；GUI 打开时的留黑点击映射已在下文的 Android Chrome 回放中单独验证。

尝试通过 Chrome 的 `chrome_devtools_remote` 抽象 socket 建立 CDP 检查，但该发布版 Chrome 没有暴露该 socket；因此未用脚本注入绕过浏览器行为，也没有将桌面 Playwright 结果混入本节。`adb reverse` 的 localhost 安全上下文和本地回放足以验证连接、解码、触控释放及旋转尺寸上报，但不代表真实手机 GPU、声音、通知、锁屏、后台冻结或公网 HTTPS/WSS 的端到端结果。


### Android Chrome GUI 留黑映射

同一 Android Chrome 本地回放中，通过可见聊天面板输入 `/replay screen open`。回放服务器收到该 `RUN_COMMAND` 后，页面调试层显示 `screen open`；没有使用 CDP 或页面脚本注入。

竖屏时，先触摸视频矩形外的底部留黑区、再触摸画面中心。回放日志只出现一条 `SCREEN_CLICK`，其 `button` 为 `0`、归一化坐标约为 `(0.499, 0.496)`。旋转为横屏后，左侧留黑区同样没有产生消息；随后触摸由实际映射测得的画面中心，日志仍只出现一条 `SCREEN_CLICK`，精确为 `(0.5, 0.5)`。

这验证了 Android Chrome 在两种方向中会拒绝图片矩形外的 GUI 触控，并把中心点映射到服务器坐标中心。回放使用黑色视频帧，边界不能靠肉眼辨认，结论来自每次触摸后回放服务器的协议日志；它仍是本地模拟器回放，不是 Minecraft 或物理手机端到端验证。

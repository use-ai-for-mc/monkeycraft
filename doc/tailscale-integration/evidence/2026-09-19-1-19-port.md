# 1.19 P3 首轮移植

日期：2026-09-19。改动仅在 `mods/1.19`；没有部署 JAR、启动 PrismLauncher/Minecraft、连接 9600、操作手机、真实 Tailscale 或账户。

## 实现范围

- 同端口 HTTP/WebSocket：加入 HTTP-aware factory、通道和静态资源服务，并在既有 WebSocket server 构造器启用 factory。端口预检逐个绑定活跃接口地址和通配地址，以捕获 macOS `SO_REUSEADDR` 下具体地址占用。
- 浏览器和 helper 资源：Gradle 在处理资源前校验四个正式 helper 的 manifest、协议版本、SHA、大小和许可证；JAR 写入 `web/dist`、四个平台 helper、各自 manifest/SHA 与许可证。`build-and-deploy.sh` 只增加构建前的 Web/helper 生成步骤，未执行该部署脚本。
- 内嵌 helper：加入当前 26.2 已覆盖的提取、生命周期、系统浏览器打开、Tailnet HTTPS 解析和状态类；自动登录、注销/停止的晚事件隔离、端口变化重启 child、重复 Auth URL 自动去重，以及显式重开均保留。默认关闭。
- 1.19 接线：配置页的 Built-in Tailscale 开关默认关闭，关闭时即时停止 helper；增加 `/monkey tailscale login|status|logout|stop`，在选择的自动启动策略成功启动服务时启动 helper，并在客户端结束时关闭。现有 Cloth UI、密码/配对、连接范围和 1.19 的 `pendingScreen` 流程保持不变。

## 旧版 API 与工具链

本地 1.19 合并 Minecraft JAR 已核对：没有 `Window.isIconified()`，因此没有移植 26.1 的 `WindowMixin`。helper 提取的线程标识使用 Java 17 的 `Thread.getId()`，而非较新的 `threadId()`。Gradle 以 Java 21 启动，并按项目 Java 17 source/toolchain 编译。

# 2026-09-18 — 26.2 desktop helper evidence

## Implemented

- The 26.2 Mod packages hash-verified helper binaries for `darwin-amd64`, `darwin-arm64`,
  `linux-amd64`, and `windows-amd64`, with the pinned Tailscale license and per-platform
  manifests.
- The Mod extracts the matching binary to its config directory, compares a sidecar SHA-256
  against the JAR resource, and replaces stale cached helpers on upgrade.
- `HelperTailscaleService` starts the helper only after the MonkeyCraft WebSocket server has a
  real port. It supplies a fresh IPC nonce, a dedicated persistent Tailscale state directory,
  and the loopback-only target `127.0.0.1:<port>`.
- The service accepts only protocol v1 messages carrying that nonce, keeps bounded redacted
  diagnostics, opens the structured Tailscale login URL in the system browser, and terminates
  the helper plus descendants when the server or Minecraft exits. Extraction and helper control
  run outside the UI thread; cancellation generations prevent a queued start from surviving a
  later stop, logout, or shutdown.
- The Network panel exposes enable, login, status, stop, and logout actions. Login uses the
  user's own Tailscale account; LAN and system Tailscale are unchanged. The panel states that
  logout removes the built-in account state and needs a later login.

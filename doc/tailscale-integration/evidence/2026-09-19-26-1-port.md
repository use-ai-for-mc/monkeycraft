# 26.1 P3 首轮移植

日期：2026-09-19。此记录是 `2026-09-19-26-1-porting-prep.md` 的实施结果。改动仅在 `mods/26.1`；没有部署 JAR、启动 PrismLauncher/Minecraft、连接真实 Tailscale、操作手机或账户。

## 实现范围

- 同端口 HTTP/WebSocket：加入 `HttpAwareWebSocketServerFactory`、`HttpOrWebSocketChannel`、`WebAssetServer`，并在 26.1 现有 WebSocket server 构造器设置 factory。端口预检改为逐个活跃地址与通配地址的 NIO bind，避免 macOS `SO_REUSEADDR` 下遗漏已占用的具体地址。
- 浏览器资源：`processResources` 先校验四个正式 helper 的 manifest、协议版本、SHA、大小和许可证，再将 helper、manifest、SHA、许可证及 `web/dist` 放入 JAR。`build-and-deploy.sh` 在 Gradle 前生成 Web bundle 与 helper 输入。
- 内嵌 helper：加入当前 26.2 的四个类，包括 headless 可用的 `SystemBrowserOpener`、注销/停止晚事件隔离、端口变更新 child、同 Auth URL 自动打开去重和显式重开。身份目录仍由 helper 使用本树的 `config/monkeycraft/tailscale-state`；默认不启动。
- 26.1 接线：保留 Cloth Config、`TailscaleAccess`、既有密码/配对协议与现有 `Minecraft.setScreen` Mixin。配置页只新增默认关闭的 Built-in Tailscale 开关；`/monkey tailscale login|status|logout|stop`、自动启动和客户端关闭接入 helper。`TailnetHttps` 只展示严格指向当前端口的既有 Serve HTTPS URL，不修改 Tailscale Serve/Funnel。
- 帧率行为：本地 26.1 API 已核实 `Window.isIconified()Z`，因此加入 `WindowMixin`。没有移植 26.2 `GuiMixin`，因为 26.1 的 `Gui` 不存在 `setScreen(Screen)`；原 `MinecraftMixin` 的 PauseScreen/窗口活动处理保持不变。

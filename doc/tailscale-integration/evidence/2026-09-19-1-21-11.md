# 1.21.11 P3 资源与内嵌 helper 回归（2026-09-19）

`mods/1.21.11` 现打包同端口 HTTP/WebSocket 静态 Web 资源，以及四个平台的内嵌 Tailscale helper、manifest 和许可证。构建会先校验每个 helper 的协议版本、平台、长度与 SHA-256；找不到 `web/dist/index.html` 或任一 helper 时会失败，不产生缺资源的 JAR。

默认配置仍关闭内嵌 Tailscale。配置页关闭开关立即停止 helper；自动启动只在该开关已启用且 MonkeyCraft 服务实际取得端口后调用 helper。`/monkey tailscale login|status|logout|stop` 使用与 26.2/26.1 相同的生命周期服务：同一 AuthURL 去重，显式重开复用缓存 URL，旧 child 的晚到事件不能重开浏览器或覆盖停止状态。HELLO 与配对请求只接受本机、LAN 或 CGNAT/Tailscale 远端地址。系统 `tailscale serve` 提示按服务实际端口调用 `TailnetHttps.probeUrl(port)`，不再固定为 9600。

HTTP 与 WebSocket 共用游戏端口；HTTP 仅提供 classpath `web/` 资源，路径遍历被拒绝。1.21.11 保留其原有 Minecraft API：命令仍使用 `ClientCommandManager`，实体交互保持此版本的双参数调用，没有套用 26.x 的 API。部署脚本在本地构建前生成 Web bundle 与 helper，但本次未执行部署。

## 验证

在 `mods/1.21.11` 使用 Java 21 执行：

```text
JAVA_HOME=/opt/homebrew/opt/openjdk@21 PATH="$JAVA_HOME/bin:$PATH" \
  ./gradlew --no-daemon spotlessApply test
JAVA_HOME=/opt/homebrew/opt/openjdk@21 PATH="$JAVA_HOME/bin:$PATH" \
  ./gradlew --no-daemon build
```

两次命令均成功。全量 JUnit 汇总为 11 suites、57 tests、0 failures、0 errors、0 skipped，包含 HTTP/WebSocket 同端口、静态资源、Tailnet HTTPS 实际端口、helper 生命周期与 AuthURL 去重/取消回归。Spotless 与 `git diff --check -- mods/1.21.11` 也通过。

生成的 `mods/1.21.11/build/libs/monkeycraft-1.4.2-1.21.11.jar` SHA-256 为：

```text
11548e2e31ae00c999de0d5ae620372621b09e3bef8d4f5b1db6b851ae4619ea
```

JAR 实际包含 `web/index.html`、`native/tailscale/LICENSE.tailscale`，以及 `darwin-amd64`、`darwin-arm64`、`linux-amd64`、`windows-amd64` 的 helper 和 `manifest.json`。

没有启动 Minecraft、连接 9600、启动真实 helper、打开登录浏览器、使用账户/auth key 或 tailnet；该离线验证不替代用户的真实 Tailscale 授权、跨设备连接和游戏内验收。

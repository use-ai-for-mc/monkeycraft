# iOS 模拟器真实 Minecraft LAN 原生流（2026-09-19）

## 范围

在已启动的 Workbench iPhone 16 iOS 26.5 模拟器（`F22F02AB-CE7D-4414-A55D-C0EE6757A84D`）上，针对实际运行中的 Minecraft 26.2 进程 PID `99326` 和端口 `9600` 执行一次 LAN 集成测试。进程加载的 JAR 为 SHA-256 以 `1a43affd0d0c86f1` 开头的当前 26.2 产物。该设备是 iOS 模拟器，不能作为物理 iPhone 验收。

测试使用生产 `StreamProxy`、`SessionController`、`HardwareH264Decoder`、`VideoSurface` 和 iOS VideoToolbox 路径。`StreamProxy.start` 使用实际本地凭据完成 HMAC 认证后，测试才订阅 access unit 并进入 native decoder。

## 执行方式与秘密处理

实际调用形式如下；`--config-path` 指向仅含 `password` 字段、权限为 `0600` 的临时 JSON。命令、Dart define、测试输出和本证据均不包含密码或一次性路由。

```text
python3 tool/run_live_native_stream.py \
  --config-path <temporary-0600-password-json> \
  --server ws://127.0.0.1:9600 \
  --device F22F02AB-CE7D-4414-A55D-C0EE6757A84D \
  --reconnect
```

运行器仅在 `127.0.0.1` 随机端口和随机路径提供一次配置读取；Dart 编译参数只携带该非长期的本地 URL。测试退出后，运行器关闭 HTTP 服务，外层 `finally` 删除临时 JSON；随后检查到 `/tmp` 中没有 `monkeycraft-live-config-*` 文件。没有改动 Prism 的原始配置权限或内容。

## 结果

测试退出码为 0，耗时约 4 秒。

| 阶段 | input access units | decoded frames | 尺寸 |
| --- | ---: | ---: | --- |
| 首次认证与流 | 8 | 8 | 360×640 |
| `SessionController` 断线重连后 | 8 | 8 | 360×640 |

每一阶段先断言 native `decodedFrames >= 5`，随后对同一 decoder 再次读取并断言至少再增长 3 帧。两阶段均通过，因此记录的 8 帧不是单次静态计数。首轮通过后，测试卸载视频管线、停止 proxy、调用 `SessionController.handleConnectionLost()`，等待其恢复连接，再重新创建 decoder 和 `VideoSurface` 后重复两次增长断言。

本次没有发送聊天、移动、按键、鼠标或游戏命令。它验证了实际 Minecraft LAN WebSocket 的认证、原生 H.264 输入与解码计数增长，以及 `SessionController` 的一次重连恢复。

## 未覆盖范围

未操作物理 iPhone、Tailscale 登录、远程 tailnet、完整游戏 UI、触控输入释放、后台运行、锁屏、音频焦点或网络切换。模拟器 loopback 运行器只适用于 iOS；Android 需要独立的端口映射和设备验证，不能据此推断已通过。

# 26.2 Java Tailscale 测试清单

测试包：`1.4.4-java-test.2-26.2`；实例：`ImagineFun Add-Ons`。
本次只接入 Minecraft 26.2，其他三个 Mod 版本及手机 App 均未修改。
面板中应显示 `Built-in Tailscale — Java (test)`，游戏日志应出现
`Embedded Tailscale backend: Java (test)`。

## 开始前

- 重启游戏以加载测试包。第一次登录会注册 `monkeycraft-java` 新设备；原生版本的登录状态保留。
- 电脑游戏和手机登录同一个 tailnet，手机端保持 Tailscale 已连接。
- 使用 Java 版面板显示的新 `100.x.x.x:端口`，不要沿用旧 helper 的地址。
- 测试远程连接时，把手机切到蜂窝网络或另一网络，确认保存的连接目标确实是新地址，避免实际走局域网而误判成功。
- 不需要为测试退出电脑的系统 Tailscale，也不需要重新安装手机 App。

## 按顺序完成的核心测试

| 顺序 | 操作 | 通过标准 |
|---|---|---|
| 1 | 重启游戏，打开 MonkeyCraft 网络设置 | 游戏正常加载，显示 `Java (test)`；已有局域网访问仍可用 |
| 2 | 点击 `Log in`，在浏览器完成账号登录；若 tailnet 要求设备批准，完成批准 | 浏览器打开一次，不反复弹窗；未批准时显示等待批准，完成后显示新地址和实际端口，不出现错误 |
| 3 | 手机上用新地址添加/修改连接并完成正常配对 | 在不同网络上能够连接，电脑收到正常配对请求，认证成功 |
| 4 | 进入世界，观看画面；移动、转向、跳跃、点击，发送聊天；切换聊天和画面模式 | 画面持续更新，操作和聊天正常，切换后可恢复画面；连续使用约 5 分钟，无持续断流或明显卡死 |
| 5 | 手机浏览器访问 `http://新地址:实际端口/` | Flutter 网页资源可完整加载，能够完成正常认证并使用；先断开手机 App，避免触发单设备限制 |
| 6 | 点击内置 Tailscale 的 `Stop`，再点 `Log in` | 该远程连接断开，游戏和局域网服务仍可用；重新启动后恢复连接，未主动退出登录时不要求重新授权 |
| 7 | 手机切换 Wi-Fi/蜂窝网络，或短暂断网再恢复，然后重连 | Java 状态能够恢复、手机可重新连接；若手机的三次自动重试已耗尽，手动连接一次即可检验恢复，不把回到登录页本身当作 Java 故障 |
| 8 | 正常退出并再次启动游戏 | 未退出 Tailscale 登录的情况下复用原设备身份和地址，不反复注册设备；手机能再次连接 |
| 9 | 最后点击 `Log out`，再点 `Log in` 完成一次重新登录 | 退出后旧会话不可继续用；重新登录正常。若显示 `remote-logout-unconfirmed`，记录该错误，不能算远端注销成功 |

## 条件允许时补充的测试

| 场景 | 操作和预期 |
|---|---|
| 电脑断网恢复 | 暂时断开电脑网络，再恢复；状态不应在监听关闭后仍显示就绪，恢复后能再次连接 |
| 游戏退出世界/回到世界 | 回主菜单后重新进世界，检查服务按现有设置启停，恢复后不重复注册设备 |
| 端口变化 | 改首选端口并重启 MonkeyCraft 服务或游戏；显示和访问的都是实际新端口，旧端口不再服务。测试后恢复原设置 |
| 后台/休眠 | 手机锁屏再返回，或电脑短暂睡眠再唤醒，确认可以恢复或手动重连 |
| 设备批准或撤销 | 仅在使用该管理功能时测试：待批准状态不得显示就绪；撤销本次 Java 测试设备后应断开，重新授权后恢复。不要操作原来的设备 |
| 中继路径 | 若日常所用网络天然无法直连，重复画面与网页加载测试；不要求为此修改路由器或防火墙，强制 DERP 已在隔离环境验证 |
| Windows x64 | 另有 Windows 机器时测试首次登录、持久化及重启；本次 Mac 实机测试不代表 Windows 已验证 |

## 实机修复记录（2026-10-04）

首次手机测试连接超时。真实控制面返回 8 个对端，但原实现错误地要求对端含有
`MachineAuthorized=true`，导致 0 个对端进入传输层。官方客户端仅将该字段用于本机授权状态。
修复后仍保留本机授权、对端过期/隔离/API-only 限制、源地址校验及 ACL。
新增协议测试先在旧实现上复现失败，再在修复后通过。
测试包 `.2` 启动后 8 个对端均进入传输层；电脑系统 Tailscale 经真实 tailnet
访问 Java 版 `100.90.70.4:9600` 返回 HTTP 200。手机画面和操作仍需单独确认。

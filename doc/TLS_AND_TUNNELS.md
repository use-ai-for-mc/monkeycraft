# TLS and Tunnel Compatibility

MonkeyCraft uses a Pin-or-WebPKI trust policy for every WSS connection:

```text
accept = SHA256(presented certificate) == scanned QR pin
      OR valid public CA chain and hostname
```

The first branch authenticates the persistent self-signed certificate generated by the mod. The
second branch permits a domain tunnel to terminate TLS with its normal public certificate. There is
no user-selectable trust mode and no fallback to accepting an arbitrary certificate.

## Direct and TCP-Passthrough Connections

LAN addresses, Tailscale IPs, raw ngrok TCP endpoints, and router port forwards preserve the TLS
connection to the mod. The app sees the mod certificate and accepts it only when its SHA-256
fingerprint matches the pairing QR. This is end-to-end TLS between the app and mod.

Changing an IP address or TCP tunnel endpoint does not change the certificate. Deleting
`config/monkeycraft-tls.p12` creates a new identity and requires scanning the QR again. A corrupt
identity fails closed and must be deliberately removed before regeneration.

## TLS-Terminating Domain Tunnels

Cloudflare Tunnel, ngrok HTTP, and Tailscale Funnel present a public CA certificate for their domain.
The app accepts that certificate through normal hostname and chain validation even though it does
not match the QR pin. These services can inspect and modify traffic because they terminate TLS; using
them means trusting the tunnel operator.

The tunnel agent must forward WebSocket upgrades to the mod's WSS origin. Configure its origin as
`https://127.0.0.1:9600` and allow the known local self-signed origin certificate using that
product's origin certificate setting. Do not disable client-to-tunnel certificate validation.

Cloudflare may close idle WebSockets, but MonkeyCraft's heartbeat keeps chat and hibernating sessions
active. Check each provider's current bandwidth limits and terms before routing the H.264 video stream
through a hosted tunnel.

## Pairing Code

The version 2 QR payload is compact JSON:

```json
{"v":2,"pw":"<password>","fp":"<base64url SHA-256 certificate fingerprint>"}
```

The app stores the password and fingerprint in platform secure storage. Legacy password-only QR
codes remain parseable but cannot authorize a direct self-signed WSS certificate.

Upgrading from a plaintext release therefore requires one new scan. If auto-start hides the in-world
QR, open the title screen, enable **Show QR Code When Auto Launch** in `/monkey config`, or stop and
manually start the MonkeyCraft server once.

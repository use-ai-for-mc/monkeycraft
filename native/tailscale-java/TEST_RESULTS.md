记录日期：2026-10-04。以下为已经执行的结果，不是后续验收承诺。测试在 macOS/Apple Silicon 上完成，使用本地临时控制服务器和测试身份。

|---|---|---|

| 独立依赖配置构建 | Java 17；完整运行依赖打包 | 通过 |
| 控制面 | Noise IK、注册、map、250 KB HTTP/2 往返 | 通过 |

| 身份与策略 | 测试登录/批准、跨 JVM 恢复、到期换钥、ACL 拒绝恢复、本地注销 | 通过 |

独立项目的完整网络互操作和并发流测试使用 Java 25 运行、Java 17 编译的本库，Go 测试工具链为 1.26.6，Tailscale 对端为 1.102.3。不能把“17/21/25 都完成协议测试”表述为新宿主依赖组合在三种 JVM 上都重跑了所有网络场景。

`docs/test-results/` 保存选取的真实日志，机器专用路径已替换为 `<workspace>`。`docs/verification.json` 记录主源码与库文件指纹、原始日志哈希以及未执行项。这些输出用于交接追溯，接手者仍可按 [TESTING.md](TESTING.md) 在自己的环境复现。文档交接更新没有修改运行代码；旧归档复建结果不代表后续改动自动通过验证。
